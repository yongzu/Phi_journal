# Phi Journal

[phi.design](https://www.phi.design) 1년제 프로그램의 매일 저널링(4F: Fact / Feeling / Finding / Future item)을
과목별로 자동 분류하고 아카이빙하는 도구입니다.

## 왜 만들었나

기존에는 하루치 저널을 통합 텍스트로 작성해 디스코드에 올렸습니다. 4F 섹션 안에 과목별 소제목(BI, AOR, SI 등)을
넣어 구분했지만, 날짜순으로만 쌓이다 보니 과목별로 인사이트를 다시 찾아보기 어려웠습니다. 이 도구는 기존과 동일한
방식으로 저널을 작성하면, 텍스트를 파싱해 과목별로 자동 정리·아카이빙합니다.

## 사용 방법

1. **오늘 작성**: 날짜를 고르고, 기존처럼 `[fact]` / `[feeling]` / `[findings]` / `[Future item]` 섹션 안에
   과목명을 소제목으로 넣어 통합 텍스트를 붙여넣습니다.
2. **파싱하기**를 눌러 미리보기를 확인합니다. 과목으로 인식되지 않는 텍스트는 "미분류" 목록으로 모입니다.
3. **이 날짜로 저장**을 누르면 과목별 아카이브에 반영됩니다.
4. **미분류** 탭에서 자동 분류에 실패한 텍스트를 과목/유형을 지정해 수동으로 합치거나 무시할 수 있습니다.
5. **과목별 아카이브** 탭에서 과목을 선택해 날짜순 타임라인으로 기록을 확인합니다.
6. **설정** 탭에서 과목 코드/이름/별칭을 실제 저널 표기에 맞게 수정하고, 데이터를 JSON으로 내보내기/가져오기할 수
   있습니다.

## 데이터 저장

이 앱은 별도 서버나 로그인 없이 **브라우저 localStorage**에만 데이터를 저장하는 정적 웹앱입니다. 브라우저 데이터를
지우면 기록이 사라질 수 있으니, 설정 탭에서 주기적으로 JSON 백업을 내보내 두는 것을 권장합니다.

## 개발

```bash
npm install
npm run dev
```

## 빌드

```bash
npm run build
```

`dist/` 폴더가 생성되며, 정적 파일이므로 GitHub Pages 등 어떤 정적 호스팅에도 바로 배포할 수 있습니다.
